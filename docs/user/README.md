# M1.1 User Documentation

M1.1 has no public end-user workflow. Its users are contributors and local operators building the
server foundation. Start with the [repository overview](../../README.md) and the
[local operations runbook](../runbook.md).

Status: planned / unverified. Public guidance for OAuth, Figma import, projects, generation, and
export must be created only in the milestone that implements and verifies those capabilities.
